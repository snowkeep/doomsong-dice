# Doomsong Dice theme package for Dice So Nice.

An add-on mocule for Dice So Nice, with the Doomcoin and Gravedigger-themed d6 dice.

The Doomcoin and dice glyphs are owned by [CeasarInk](https://caesar.ink/), the creators of [Doomsong](https://caesar.ink/viewproduct/5/doomsong-corebook).
The dice are based on my [Mouthful of Teeth](https://github.com/snowkeep/mouthful-of-teeth-dice/) theme and the Grifter dice from
[Dice More Nice](https://github.com/LyncsCwtsh/fvtt-module-nice-more-dice).

Thank you to artaey on the Caesar Ink discord for the 3d Doomcoin model.
